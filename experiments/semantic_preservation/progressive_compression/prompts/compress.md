# Compression Prompt

You are compressing a text while preserving its core meaning.

## Task

Given a text, produce a compressed version that is approximately {target_fraction} of the original length.

The compressed text must:
- Preserve all essential information, claims, and relationships
- Remove redundancy, elaboration, and stylistic elements first
- Maintain logical coherence and flow
- Be grammatically correct
- Not introduce new information
- Not change the meaning of any preserved claim

## Output Format

Output only the compressed text. Do not include any preamble, explanation, or commentary.

## Original Text ({source_language})

{text}
